# 보안 안내

## Windows SmartScreen 경고

현재 DeskCare는 **디지털 서명되지 않은 실행 파일**입니다. Microsoft Defender SmartScreen에서 인식되지 않는 앱으로 표시될 수 있습니다. 이는 파일 자체의 악성 여부를 확정하는 알림은 아니며, 보안 기능을 끄는 것이 해결책은 아닙니다.

- 파일을 공식 저장소에서만 내려받으세요.
- 배포 파일의 체크섬과 출처를 확인하세요.
- 바이러스 검사 후 사용하세요.
- 신뢰할 수 없는 경우 실행하지 마세요.
- 공개 배포 전 서명, 바이러스 검사, Windows 환경의 독립적인 보안 테스트를 권장합니다.

## v1.8의 보안 강화

- 웹 인터페이스에 연결된 로컬 서버는 루프백 주소에서만 서비스를 제공하도록 설계되었습니다.
- Host와 Origin 검증으로 다른 웹사이트에서 로컬 서버로 요청하는 위험을 줄입니다.
- JSON 본문의 크기·형식 제한을 적용합니다.
- CSV 파일에 수식 문자열이 주입되어 스프레드시트에서 실행되는 위험을 줄입니다.
- 추가 보호를 꺼도 실행·설치·설정·백업 파일의 정리를 차단합니다.

## 남은 위험

- 파일 검사와 이동 사이에 다른 프로세스가 파일 또는 경로를 변경할 수 있습니다.
- 경로 판별로 모든 Windows 링크/재분석 지점 유형을 완벽히 보장할 수 없습니다.
- 검사 코드를 우회하는 사용자 또는 악성 프로세스가 있을 수 있습니다.
- 실제 사용자 장치에서 충분한 보안·안정성 테스트가 완료되지 않았습니다.

중요한 파일은 별도로 백업하고, 자동 보호 사용을 기본으로 두세요.

## 취약점 신고

민감한 시스템 정보, 개인 파일 및 비밀번호는 **공개 GitHub Issue에 올리지 마세요**. 저장소 소유자에게 비공개 방식으로 신고하는 것을 권장합니다.
