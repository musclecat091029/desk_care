# DeskCare 사용설명서

## 1. 실행하기

1. 향후 [Releases](https://github.com/musclecat091029/desk_care/releases)에 올라오는 `deskcare_window_1.8.exe`를 내려받습니다.
2. 프로그램이 이미 실행 중이면 완전히 종료합니다.
3. EXE를 두 번 클릭하여 실행합니다. 별도 설치 프로그램이 없습니다.
4. Windows Defender SmartScreen 경고가 나타나면 파일 출처와 검사를 먼저 확인하세요. 이 프로그램은 코드 서명이 없습니다.

**현재 GitHub 저장소에는 아직 EXE가 게시되지 않았습니다.**

## 2. 저장공간 분석

1. 대시보드에서 C: 드라이브의 사용량을 확인합니다.
2. 사용자 폴더(예: 다운로드, 사진, 문서)를 선택하고 분석을 시작합니다.
3. 분류된 결과에서 파일 이름, 크기, 수정일, 실제 위치를 확인합니다.

시스템 폴더나 보호된 폴더는 자동으로 제외될 수 있습니다. 이는 프로그램 오류가 아니라 파일 손상을 방지하기 위한 설계입니다.

## 3. 스마트 정리

- **큰 파일**: 200MB 이상의 파일 찾기
- **오래된 다운로드**: 90일 이상 된 다운로드 파일 찾기
- **설치 파일**: 설치 파일 확인. 보호된 파일은 직접 삭제하지 않는 것이 좋습니다.
- **중복 파일**: 파일 크기와 SHA-256 해시를 비교하여 **동일한 바이트**의 파일만 그룹화

사진 내용이 비슷해도 파일 데이터가 다르면 중복으로 나오지 않습니다. 각 중복 그룹에서 반드시 보존할 사본을 직접 확인하세요.

## 4. 자동 보호

- **보호 항목 표시**: 보호된 파일을 목록에 표시하거나 숨김
- **자동 보호 사용**: 특정 파일 유형에 대한 추가 보호를 켜거나 끔

두 설정은 독립적이며, 자동 보호를 꺼도 핵심 시스템·프로그램 및 일부 위험 확장자 보호는 유지됩니다. 보호 해제가 곧 '안전하게 삭제해도 된다'는 의미는 아닙니다.

## 5. 휴지통으로 이동

1. 선택한 파일의 **경로·이름·수정일**을 확인합니다.
2. 보호되지 않은 파일을 선택합니다.
3. **선택한 파일 휴지통으로 이동** 버튼을 누릅니다.
4. 결과를 확인합니다. 파일 이동 후 오류가 떴다면 다시 누르기 전에 Windows 휴지통을 확인하세요.

휴지통에서 마우스 오른쪽 버튼을 눌러 **복원**할 수 있습니다. 휴지통을 비우면 복원이 어려울 수 있습니다.

## 6. 설치된 앱

설치된 앱 목록은 Windows에 등록된 정보를 보여줍니다. 신고된 용량은 실제 디스크 사용량과 다를 수 있으며, 앱 제거는 Windows **설정 → 앱 → 설치된 앱**에서 진행합니다.

## 7. 종료와 제거

- 창 오른쪽 위 **X**를 눌러 종료할 수 있도록 구현했습니다.
- 종료 뒤에도 프로세스가 남으면 작업 관리자에서 DeskCare 프로세스를 종료합니다.
- EXE를 삭제하면 프로그램을 제거할 수 있습니다. 기존 개인 파일은 함께 삭제되지 않습니다.

## 8. 업데이트

v1.8은 아직 온라인 업데이트 알림 기능이 없습니다. 향후 [Releases](https://github.com/musclecat091029/desk_care/releases)에서 버전을 확인하세요.
