# DeskCare 1.9 사용설명서

> **다운로드**: [DeskCare v1.9 릴리스](https://github.com/musclecat091029/desk_care/releases/tag/v1.9)에서 `deskcare_window_1.9.exe`와 `SHA256SUMS.txt`를 받을 수 있습니다. **디지털 서명이 없고 Windows 실기기 검증이 완료되지 않은 사전 출시**입니다.

## 1. 시작하기

1. [릴리스](https://github.com/musclecat091029/desk_care/releases/tag/v1.9)에서 `deskcare_window_1.9.exe`를 다운로드하고 SHA-256을 확인합니다.
2. 기존 DeskCare를 실행 중이라면 창을 닫아 완전히 종료합니다. 남아 있는 프로세스는 작업 관리자에서 종료합니다.
3. EXE를 실행하고 분석할 사용자 폴더를 고릅니다.
4. **선택한 폴더 분석** 버튼으로 파일 목록을 생성합니다.

설치 프로그램이나 Python은 필요하지 않도록 빌드되어 있습니다. 코드 서명이 없어 Windows SmartScreen 경고가 표시될 수 있습니다. 파일 출처와 백신 검사 결과를 먼저 확인하세요.

## 2. 대시보드와 전체 파일

- **대시보드**: 드라이브 전체 사용량과 분석한 파일의 유형별 용량을 표시합니다. 드라이브 사용량과 분석한 폴더 용량의 합계는 다를 수 있습니다.
- **전체 파일**: 파일명·경로 검색, 파일 종류별 필터, 크기·날짜별 정렬, CSV 내보내기를 지원합니다.
- **스마트 필터**: 큰 파일(200MB 이상), 오래된 파일(90일 이상), 오래된 다운로드(90일 이상), 설치 파일, 중복 파일을 전체 파일 화면에서 확인할 수 있습니다.

## 3. 스마트 정리

**스마트 정리와 전체 파일 화면은 사용자가 분석한 동일한 파일 목록을 사용합니다.** 설치된 앱 목록을 스마트 정리 대상으로 사용하는 것은 아닙니다.

스마트 정리에서 **전체 파일에서 보기**를 누르면 해당 조건의 필터가 적용된 전체 파일 화면으로 이동합니다.

- **큰 파일**: 200MB 이상
- **오래된 파일**: 분석한 모든 사용자 폴더에서 수정한 지 90일 이상
- **오래된 다운로드**: Downloads 폴더에 있는 90일 이상 파일
- **설치 파일**: EXE·MSI 등 실행 또는 설치 파일 목록 (안전을 위해 삭제 후보에서 보호)
- **중복 파일**: 크기와 SHA-256 해시로 내용이 같은 파일 비교

‘오래된 파일’은 사용되지 않는 파일과 다릅니다. 삭제 전 경로와 사용 목적을 확인하세요.

## 4. 설치된 앱에서 설치 경로 확인

설치된 앱에는 Windows에 등록된 프로그램 이름·게시자·추정 크기와 **설치 경로**가 표시됩니다.

- `InstallLocation`이 Windows에 등록되면 해당 경로를 표시합니다.
- 등록 정보가 없으면 **경로 미제공**으로 표시합니다.
- 경로가 등록되어 있지만 존재하지 않으면 **경로 없음**으로 표시합니다.
- 실제 존재하는 폴더만 **폴더 열기**로 열 수 있습니다.

설치 폴더를 직접 삭제해 프로그램을 제거하지 마세요. 앱 제거는 **Windows 설정 → 앱 → 설치된 앱**을 이용해야 합니다.

## 5. 자동 보호와 파일 삭제

**보호 항목 표시**는 보호된 항목의 목록 표시를 켜거나 끄는 UI 옵션이고, **자동 보호 사용**은 일반 파일에 대한 추가 제한을 제어하는 옵션입니다.

자동 보호를 꺼도 핵심 시스템·프로그램 경로, 실행·설치·압축·설정·백업 파일은 보호됩니다. 해제 시 일반 텍스트 파일 중 일부가 추가 후보가 되지만, 중요 파일일 가능성은 남습니다.

파일을 휴지통으로 옮기려면:
1. 삭제할 파일의 **이름·경로·수정일**을 확인합니다.
2. 보호되지 않은 파일만 선택합니다.
3. **휴지통으로 이동** 버튼과 확인창을 사용합니다.
4. 결과 표시에서 오류가 나도 **재시도 전에 Windows 휴지통을 확인**합니다.

휴지통은 백업이 아니므로 중요한 파일은 별도 저장장치에 복사해 두세요.

## 6. 종료와 업데이트

- 앱 창 **X**로 종료하도록 구현되어 있습니다. 프로세스가 남으면 작업 관리자에서 종료하세요.
- 프로그램 제거는 종료 후 EXE 삭제로 가능합니다. 개인 파일은 함께 삭제되지 않습니다.
- 현재 1.9에는 업데이트 알림이 없습니다. 출시 정보를 [GitHub Releases](https://github.com/musclecat091029/desk_care/releases)에서 확인하세요.
