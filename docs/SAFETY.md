# 파일 정리 안전 가이드

DeskCare는 **불필요한 파일을 확정하는 프로그램이 아니라 정리 후보를 보여주는 도구**입니다.

## 자동 보호가 필요한 이유

프로그램 실행·설정·데이터베이스 파일은 수년간 수정되지 않아도 중요한 파일일 수 있습니다. 파일 이름이나 크기만으로 삭제 가능성을 판단하지 마세요.

### 기본 보호 원칙

- Windows 시스템 및 응용프로그램 폴더는 분석·삭제 대상에서 제외
- 실행 파일, 설치 파일, 설정 파일, 데이터베이스, 압축 백업 등은 보수적으로 보호
- 심볼릭 링크·정션 등 우회 경로와 일부 동기화 경로는 제한
- 파일 삭제 요청 직전에 경로 및 보호 여부를 다시 확인
- 중복 그룹의 마지막 사본은 보존
- 사용자의 확인 없이 자동 삭제하지 않음

**한계:** 중요한 문서나 사진은 어떤 외부 프로그램에 의해 참조될 수도 있습니다. 자동 보호 로직이 모든 의존성을 알아내는 것은 불가능합니다.

### 삭제 전 체크

1. 실제 파일 위치를 확인합니다.
2. 백업 또는 다른 사본이 있는지 점검합니다.
3. 삭제해도 업무에 문제가 없는지 직접 판단합니다.
4. 먼저 휴지통으로 이동합니다.
5. 며칠간 이상이 없는지 확인한 뒤 휴지통을 비웁니다.

프로그램에서 에러 메시지가 나타난 경우에도 휴지통 이동이 완료되었을 수 있으니 **중복해서 삭제 명령을 실행하지 마세요.**
