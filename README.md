# DeskCare

**Windows를 위한 간편한 저장공간 분석·파일 정리 도구**  
**v1.9** · Windows 10/11 (64비트) · 한국어 · 설치 없는 포터블 프로그램

파일을 사진·동영상·문서 등으로 나눠 용량을 확인하고, 중복·대용량·오래된 파일을 찾아 **직접 선택한 파일만 휴지통으로 이동**합니다.

> **다운로드 상태:** 소스코드는 이 저장소에서 확인할 수 있습니다. **Windows 실행 파일은 아직 GitHub Releases에 게시되지 않았습니다.** [Releases 보기](https://github.com/musclecat091029/desk_care/releases)

## 기능

| 기능 | 내용 |
| --- | --- |
| 저장공간 분석 | 사진·동영상·문서·음악·압축 파일 등 유형별 사용량 |
| 전체 파일 | 파일명·경로 검색, 용량/날짜 정렬, 종류별 필터 |
| 스마트 정리 | 200MB 이상 파일, 90일 이상 파일, 오래된 다운로드, 설치 파일, 중복 파일 |
| 중복 검사 | 파일 크기와 SHA-256을 이용한 **내용이 동일한 파일** 비교 |
| 설치된 앱 | Windows에 등록된 앱 목록·추정 용량·**설치 경로** 확인 |
| 안전한 정리 | 자동 보호와 삭제 직전 재검사, 선택 파일을 Windows 휴지통으로 이동 |

**v1.9 변경점:** 설치된 앱에 경로와 ‘폴더 열기’ 기능이 추가됐고, 스마트 정리에서 **‘전체 파일에서 보기’**를 누르면 동일한 조건의 파일 목록으로 이동합니다. [전체 변경 기록](CHANGELOG.md)

## 실행 및 사용

1. 공식 배포가 완료되면 [GitHub Releases](https://github.com/musclecat091029/desk_care/releases)에서 `deskcare_window_1.9.exe`를 내려받습니다.
2. 기존 DeskCare를 종료한 뒤 EXE를 실행합니다. 일반 사용자에게 Go 또는 Python 설치는 필요하지 않습니다.
3. **사용자 폴더 선택 → 분석 → 파일 확인 → 휴지통으로 이동** 순서로 사용합니다.

**주의:** ‘오래된 파일’이 반드시 불필요한 파일을 의미하지는 않습니다. 프로그램에 필요한 파일이나 중요한 자료도 오래된 것으로 표시될 수 있습니다. 자동 보호를 끈 상태에서도 중요한 파일은 백업 후 정리하세요. 설치된 앱은 프로그램 폴더를 직접 삭제하지 말고 **Windows 설정 → 앱 → 설치된 앱**에서 제거해야 합니다.

### Windows 보안 경고

현재 EXE는 **디지털 서명이 없습니다.** Windows SmartScreen 경고가 표시될 수 있으며, 코드만 수정한다고 경고가 사라지지는 않습니다. 배포 출처와 파일 검사를 확인하고, Windows 보안 기능을 끄지 마세요. Windows 실기기 및 독립적인 보안 검증은 계속 필요합니다.

## 개발자용

```text
.
├── main.go / platform_*.go / safety*.go  # Go 프로그램 및 플랫폼별 기능
├── *_test.go                             # 같은 Go 패키지의 테스트
├── go.mod                                # Go 1.23
├── ui/                                   # 웹 기반 데스크톱 UI (Go embed)
├── assets/windows/                       # 고양이 앱 아이콘·Windows 리소스
├── scripts/                              # 아이콘 삽입 및 긴급 종료 도구
├── docs/                                 # 사용자·보안·배포 문서
├── .github/workflows/ci.yml             # 자동 테스트 및 Windows 빌드
└── build_windows.bat                     # Windows 64비트 빌드
```

요구 사항: **Go 1.23**, Windows 아이콘 빌드용 **Python 3**.

```powershell
go test ./...
.\build_windows.bat
```

CI에서는 Go 테스트, Windows 바이너리 빌드 및 아이콘 삽입을 검증합니다. **CI 성공이 바이러스 검사나 코드 서명을 대신하지는 않습니다.**

라이선스는 아직 명시되지 않았습니다. 공개 저장소라도 별도 허가 없이 자유로운 재배포·상업적 이용 권한이 생기지는 않습니다.
