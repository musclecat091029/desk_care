# DeskCare

**Windows 노트북을 위한 저장공간 분석·안전한 파일 정리 프로그램**

현재 버전: **1.8** · 지원: **Windows 10/11 (64-bit)** · UI: 한국어

DeskCare는 사진, 동영상, 문서, 압축 파일 등 저장공간을 유형별로 확인하고, 용량이 큰 파일이나 내용이 완전히 같은 중복 파일을 정리하도록 도와주는 데스크톱 도구입니다. 별도의 설치 과정 없이 EXE로 실행하는 포터블 프로그램입니다.

> **배포 상태**: 이 저장소에는 사용설명서와 배포 안내를 먼저 게시했습니다. **EXE 및 전체 소스코드는 아직 GitHub에 업로드되지 않았습니다.** 본 저장소의 다운로드 링크가 준비되기 전에는 [Releases](https://github.com/musclecat091029/desk_care/releases)를 확인해 주세요.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 저장공간 대시보드 | 드라이브의 사용량과 남은 용량 |
| 파일 종류별 분석 | 사진·동영상·문서·음악·압축 파일 등 분류 |
| 전체 파일 목록 | 파일명·크기·수정일 기준 검색과 정렬 |
| 대용량 파일 찾기 | 200MB 이상 파일 탐색 |
| 오래된 다운로드 | 90일 이상 된 다운로드 파일 확인 |
| 중복 파일 검사 | 파일 크기 및 SHA-256 해시 비교 |
| 설치된 앱 목록 | Windows에 등록된 앱과 신고된 용량 확인 |
| 자동 보호 | 시스템·프로그램·설정 관련 항목의 삭제 방지 |
| 휴지통 정리 | 사용자가 선택하고 확인한 파일만 Windows 휴지통으로 이동 |

파일 중복은 **내용이 같은지**를 기준으로 검사합니다. 이름이 다르더라도 바이트가 같으면 중복으로 탐지할 수 있고, 비슷하게 보이는 사진을 찾아내는 기능은 아닙니다.

## 설치 및 실행

1. 추후 [Releases](https://github.com/musclecat091029/desk_care/releases)에서 `deskcare_window_1.8.exe`를 받습니다.
2. 이전 DeskCare가 열려 있다면 창을 닫고 실행 프로세스가 종료되었는지 확인합니다.
3. EXE를 실행합니다. 별도의 설치나 Python 설치는 필요하지 않습니다.
4. 분석할 사용자 폴더를 선택하고 **선택한 폴더 분석**을 누릅니다.
5. 정리 후보의 이름·경로·수정일을 확인한 후, 필요한 파일만 선택하여 휴지통으로 이동합니다.

보안 정책에 의해 EXE 실행이 차단되면 보안 기능을 끄기 전에 파일 출처와 바이러스 검사 결과를 확인하세요. **현재 빌드는 코드 서명이 없어서 SmartScreen 경고가 표시될 수 있습니다.** 경고가 뜨지 않는다고 파일이 무조건 안전한 것은 아닙니다.

자세한 사용법: [사용설명서](docs/USAGE.md) · [안전하게 파일 정리하기](docs/SAFETY.md) · [보안 안내](docs/SECURITY.md)

## 안전 관련 주의사항

- **'오래된 파일'은 '불필요한 파일'과 다릅니다.** 현재 프로그램에 필요한 데이터도 오래된 것으로 탐지될 수 있습니다.
- 자동 보호를 꺼도 시스템·프로그램과 특정 위험 파일 경로는 계속 차단하도록 설계되어 있지만 **완전한 안전을 보장하지 않습니다**.
- 중복 파일을 삭제하기 전에는 어느 사본을 남겨야 하는지 확인하세요.
- 삭제는 휴지통으로 이동하는 방식입니다. **작업 후 오류가 뜨더라도 다시 누르기 전에 휴지통을 확인**하세요.
- 중요한 자료는 별도 백업을 권장합니다.

## 프로그램 종료 및 제거

DeskCare 창의 **X**로 종료하도록 설계되어 있습니다. Windows 환경에 따라 백그라운드 프로세스가 남으면 작업 관리자에서 `deskcare_window_1.8.exe`를 종료하세요. 프로그램을 제거하려면 종료 후 EXE를 삭제하면 됩니다. 분석했던 개인 파일은 프로그램을 지운다고 함께 삭제되지 않습니다.

## 개발 및 빌드

현재 구현은 Go + HTML/CSS/JavaScript이며 로컬 인터페이스는 `127.0.0.1`에서 동작하도록 작성되었습니다. 소스코드를 등록한 뒤에는 Windows에서 다음과 같이 테스트 및 빌드합니다.

```powershell
go test ./...
.\build_windows.bat
```

실행 파일에는 Go나 Python이 필요하지 않습니다. 소스 빌드에는 Go가 필요하며 아이콘 리소스를 만드는 스크립트는 Python을 요구할 수 있습니다.

## 배포 및 업데이트

향후 버전 배포는 GitHub **Releases**로 진행할 계획입니다. 현 버전에는 실행 중 자동 업데이트 확인 기능이 없으므로, 업데이트는 Releases를 직접 확인해야 합니다.

**검증 범위**: 자동화된 코드 테스트와 Windows 바이너리 빌드는 수행했지만 실제 여러 Windows PC에서의 안정성 및 보안 검증은 별도로 필요합니다.

**라이선스**: 아직 별도로 지정되지 않았습니다. 공개 저장소라도 별도의 라이선스 없이 제3자에게 수정·재배포 권한이 자동 부여되지는 않습니다.
