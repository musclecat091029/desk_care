# DeskCare

Windows 노트북을 위한 **저장공간 분석·안전한 파일 정리 프로그램**

**최신 제작 버전: 1.9** · Windows 10/11 (64비트) · 한국어 UI · 포터블 EXE

> **배포 상태 (2026-11-24):** GitHub의 설명서는 1.9에 맞게 갱신되었습니다. **Go 백엔드·웹 UI·테스트 및 아이콘 리소스의 전체 소스는 이 저장소에 올라와 있습니다. Windows EXE는 아직 Releases에 등록되지 않았습니다.** 다운로드용 GitHub 릴리스가 공개되기 전까지는 [배포 상태 및 업로드 방법](docs/RELEASE.md)을 참고하세요.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 저장공간 대시보드 | 드라이브 사용량 및 선택한 폴더의 분석 결과 |
| 사진·동영상·문서 분류 | 파일 유형별 사용 용량 확인 |
| 전체 파일 | 파일명·경로 검색, 종류별 분류, 크기·날짜 정렬 |
| 스마트 정리 | 큰 파일(200MB+), 오래된 파일(90일+), 오래된 다운로드, 설치 파일, 중복 파일 |
| **스마트 정리 ↔ 전체 파일** | 같은 분석 결과를 사용하고 ‘전체 파일에서 보기’로 해당 필터 이동 |
| **설치된 앱** | Windows에 등록된 앱 용량 및 **설치 경로 표시**, 확인된 경로의 폴더 열기 |
| 중복 검사 | 파일 크기와 SHA-256 해시 비교로 내용이 같은 파일 찾기 |
| 자동 보호 | 시스템·프로그램 파일 보호, 보호 항목 표시/숨김, 추가 보호 설정 |
| 휴지통 이동 | 사용자가 선택한 파일만 확인 후 휴지통으로 이동 |

### 1.9에서 달라진 점

**① 설치된 앱 경로**: Windows가 제공하는 `InstallLocation`을 보여줍니다. 없으면 **경로 미제공**, 등록된 경로가 실제 존재하지 않으면 **경로 없음**으로 표시하며 임의 추측하지 않습니다.

**② 스마트 정리와 전체 파일 통합**: 두 화면이 동일한 파일 분석 결과를 사용합니다. 스마트 정리의 **전체 파일에서 보기**를 누르면 큰 파일·오래된 파일·설치 파일·중복 파일 등 해당 필터가 적용됩니다.

**③ 오래된 파일 범위 확대**: 기존의 오래된 다운로드 외에, 사용자가 분석 대상으로 선택한 폴더 전체에서 수정 후 90일 이상 지난 파일을 별도로 볼 수 있습니다.

## 실행 방법

1. 출시된 EXE 파일 `deskcare_window_1.9.exe`를 공식 출처에서 다운로드합니다. **현재 이 GitHub 저장소에는 아직 EXE가 등록되지 않았습니다.**
2. 이전 버전이 실행 중이면 DeskCare 창을 닫고, 필요 시 작업 관리자에서 남은 프로세스를 종료합니다.
3. EXE를 더블클릭합니다. 설치 프로그램 또는 Python 설치 없이 실행할 수 있도록 만들어졌습니다.
4. 사용자 폴더(예: 다운로드, 문서, 사진)를 골라 **선택한 폴더 분석**을 누릅니다.
5. 용량·경로·수정일을 확인하고 정리할 파일만 선택하여 **휴지통으로 이동**합니다.

## 삭제 시 주의사항

- **오래된 파일이 불필요한 파일이라는 뜻은 아닙니다.** 사진·문서도 프로그램이 참조할 수 있습니다.
- 자동 보호를 꺼도 Windows 시스템·프로그램 폴더와 실행·설치·설정·백업 파일은 보호하도록 설계했습니다. 그렇더라도 삭제 전 중요성을 직접 확인하세요.
- ‘설치된 앱’의 **폴더 열기**는 설치 폴더를 보여줄 뿐, 해당 폴더를 지우라는 뜻이 아닙니다. 앱 제거는 **Windows 설정 → 앱 → 설치된 앱**을 이용하세요.
- 중복 검사는 파일 이름이 아니라 크기와 SHA-256을 기준으로 하므로, 이름이 달라도 같다고 나올 수 있습니다.
- 휴지통 이동 후 오류가 보이면 **재시도하기 전 휴지통을 먼저 확인**하세요.

## 안전성과 운영 한계

DeskCare는 파일 시스템을 다루므로 중요한 자료는 반드시 별도 백업 후 사용하세요. 자동 검사만으로 삭제 위험을 완전히 판정할 수 없으며, Windows 실기기에서의 폭넓은 보안 검증도 완료되지 않았습니다.

**Windows SmartScreen**: 현재 EXE는 디지털 서명이 없어 경고가 나타날 수 있습니다. 보안 설정을 끄지 말고 다운로드 출처와 바이러스 검사 결과를 확인하세요.

**자동 업데이트 알림**: 1.9에는 없습니다. 새 버전은 추후 [GitHub Releases](https://github.com/musclecat091029/desk_care/releases)에서 확인하는 방식으로 제공할 예정입니다.

## 개발 및 빌드

구성: **Go 1.23 + HTML/CSS/JavaScript**, 로컬 인터페이스 `127.0.0.1`.

```powershell
go test ./...
.\build_windows.bat
```

전체 소스코드는 저장소에 게시되어 있어 내려받아 빌드할 수 있습니다. 빌드 도구는 Go를 사용하며 아이콘 리소스 생성에 Python이 필요할 수 있습니다. 완성된 EXE 실행에는 Go/Python이 필요하지 않습니다.
